## Field guidance

- **Type:** Feature / Bug / Improvement / Technical Debt / Security / Compliance / Documentation / Research.
- **Decision:** Proposed / Under Review / Accepted / Rejected / Deferred.
- **Priority:** P0 / P1 / P2 / P3, with rationale in the brief or decision note. Leave blank until assessed.
- **Delivery:** Not Planned / Planned / In Progress / Blocked / Implemented / Verified / Completed / Cancelled.
- **Source:** Link to the discussion, issue, review, test, incident, or other evidence. Redact sensitive data.
- **Owner:** Person accountable for triage or delivery; do not invent one.
- **Dependencies / related:** Stable IDs or links. Identify blocking dependencies explicitly.
- **Brief / delivery links:** Feature Brief, issue, PR, commit, test evidence, or release record.
